# Arpeggi — personal website

A small personal site for music, experiments, and software projects.

## Structure

- `index.html` — semantic page content and metadata
- `styles.css` — visual design, responsive layout, and reduced-motion support
- `script.js` — theme toggle and current footer year
- `assets/imgs/` — existing site image assets

## Local preview

Open `index.html` in a browser, or serve this directory with any static HTTP server. No build step or package installation is required.
